# Local development / test dependencies.
#
# requirements.txt is the Emergent *deployment* manifest: it pins the whole
# platform image (pandas, boto3, litellm, google-genai, s5cmd ...) and several
# of those pins do not build on Windows. This file is the minimum needed to
# actually run `uvicorn server:app` and `pytest` on a developer machine.
#
# Everything server.py needs at import time is listed here. The two heavyweight
# integrations are imported lazily *inside* functions -- `emergentintegrations`
# (AI) and `resend` (email) -- so the app boots and the suite runs without them;
# the code paths that use them are skipped locally. Phase 4 puts both behind
# provider interfaces with null implementations so this stops being incidental.
#
#   py -3.12 -m venv .venv
#   .venv/Scripts/python -m pip install -r requirements-local.txt
